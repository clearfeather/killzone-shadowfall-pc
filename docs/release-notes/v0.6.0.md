## 🎮 Xbox button icons (new)

*Launcher → Controls → Keyboard and mouse → In-game button icons · or Insert → Controls → Button prompts*

| Option | Shows |
|---|---|
| **Automatic** (default) | Keyboard keys while you use keyboard and mouse; with a controller, **PS4 icons on PlayStation controllers and Xbox icons on any other** |
| **Keyboard and mouse** | Always your keys |
| **PS4** | Always the original icons |
| **Xbox** | Always A / B / X / Y, LB / RB, LT / RT, LS / RS, Menu, View and the D-pad |

The Xbox icons are drawn in the same style as the game's HUD and follow **your controller mapping**
if you changed it.

## 🏔️ Detail distance — LOD (new)

*Launcher → Graphics → Image → **Detail distance (LOD)** · or **live** in Insert → Image → Level of detail*

How far characters and objects keep their **detailed models**:

| Setting | Result |
|---|---|
| **50% – 75%** | Detail drops sooner: **more FPS** (up to +15-20 FPS in some areas on our PC) |
| **100%** | As on PS4 |
| **150% – 300%** | Detailed models further away: **less pop-in**, more GPU and CPU load |

## 🔭 FOV up to 200% (new)

The field of view slider now goes **from 80% to 200%** (before, 150%), in the launcher and live in
the in-game menu.

## 🛟 Better crash messages

When the game closes with an error, the launcher now tells you the **likely cause** and what to do:
not enough **page file** / memory, the graphics card **ran out of VRAM**, the **driver reset the
GPU**, or the game's own error message.

## 🚀 Other improvements

- **Faster, more correct shaders** (fixes backported from shadPS4 and the shared PS4 core):
  NaN clamping, real `RCP/RSQ_CLAMP`, branch masks, maximal reconvergence on compute.
- **Alt-tab** and minimizing in fullscreen no longer break the image.
- **Audio:** if WASAPI fails to open, the game falls back to **DirectSound** instead of silence.
- **Fewer CPU costs** on the GPU threads (descriptor and sampler reuse, memory tracking).
- If Windows can't reserve the game memory, a clear message about the **page file** instead of a
  later crash.

## 🔜 What's next

The port now has almost everything we planned. **From here on, the work is mostly about:**

- 🐞 **Stability and crashes**, above all on **Intel Arc** and **AMD** graphics.
- 🧩 **Compatibility** with other regions and dumps, and the open issues.
- 🌍 **More languages in the launcher.**
- ✨ New features only if something important comes up.

## 🛟 Mejores mensajes al crashear

Cuando el juego se cierra con un error, el launcher ahora te dice la **causa probable** y qué hacer:
falta **archivo de paginación** / memoria, la placa **se quedó sin VRAM**, el **driver reinició la
GPU**, o el mensaje de error del propio juego.

## 🚀 Otras mejoras

- **Shaders más rápidos y correctos** (correcciones traídas de shadPS4 y del núcleo PS4 compartido):
  acotado de NaN, `RCP/RSQ_CLAMP` reales, máscaras de saltos, maximal reconvergence en compute.
- **Alt-tab** y minimizar en pantalla completa ya no rompen la imagen.
- **Audio:** si WASAPI no puede abrirse, el juego pasa a **DirectSound** en vez de quedarse mudo.
- **Menos costo de CPU** en los hilos de la GPU (reutilización de descriptores y samplers, rastreo
  de memoria).
- Si Windows no puede reservar la memoria del juego, un mensaje claro sobre el **archivo de
  paginación** en vez de un crash más adelante.
